﻿无界鼠标独立便携版 / Mouse Without Borders Standalone
版本：0.102.2933.18（音频断点平滑与缓冲修复；基于 Microsoft PowerToys v0.102.2933.0）
构建日期：2026-10-24

这是什么
这是从微软 PowerToys 当前稳定版源码拆分、修改并重新编译的独立版本，
不是微软官方签名发布的独立安装包。无需安装 PowerToys，也无需单独安装 .NET。
适用于 Windows 11 x64、Windows 10 x64 2004 或更新系统。
本机验证环境为 Windows 11 x64（系统版本 10.0.26200）。未在 Windows 10 上实测。

开始使用
1. 在两台电脑上解压整个 ZIP 到各自固定文件夹，不要只复制 EXE。
2. 先退出旧版无界鼠标，并关闭 PowerToys 中的 Mouse Without Borders 模块。
3. 两台电脑连接同一可信局域网，双击 MouseWithoutBorders.exe。
4. 首次启动若 Windows 防火墙询问联网权限，请按你实际的网络情况自行处理。
   建议在可信的专用网络使用；不要为此关闭防火墙。程序使用 TCP 15100、15101。
5. 第一台电脑在向导中选择“否”，查看本机配对码和本机名称。
6. 第二台电脑选择“是”，填入第一台的配对码和计算机名，点击“连接”。
7. 配对完成后，在“电脑排列”中按桌面的实际左右位置排列电脑，点击“应用”。
8. 将鼠标移过屏幕边缘即可控制另一台电脑，键盘输入随鼠标所在电脑切换。
   托盘图标可打开设置和退出程序；不需要自己运行 MouseWithoutBordersHelper.exe。

日常使用
- .18 对两种模式的声音断点做5ms平滑：包括缓冲耗尽、恢复、接收追赶和发送丢帧，连续音频保持原样。
  稳定模式增加80ms起步的预缓冲，随欠载增加但不超过配置容量或200ms，可能增加延迟。
  低延迟系统声音改为事件驱动采集，采集容量60ms；麦克风采集容量也为60ms。
  两台都更新后，先关闭自适应低延迟并点击“保存并应用”试听，再比较开启后的效果。
  自动测试和本机声卡测试已通过；不能据此保证所有设备、网络上的爆破声都已消除。
- .17 把低延迟改为“自适应低延迟”：先预缓冲40ms，根据实际播放读取块和欠载逐步增加至最多100ms。
  请求40ms播放缓冲，低延迟接收队列上限160ms；溢出追赶时保留抗抖动余量，重缓冲边界短暂淡入淡出。
  采集发送队列可容纳最多12个10ms帧，超过160ms的旧帧不再发送，避免轻微调度抖动就截掉声音。
  接收状态显示预缓冲目标、欠载次数和追赶丢弃量；音源暂停也可能触发一次欠载，不能把这个计数直接当Wi-Fi丢包率。
  保留升级前的低延迟开关；关闭时使用稳定模式（.18起也有预缓冲与断点平滑）。请两台升级后再勾选自适应低延迟试听，保存后会同步。
  这些都是软件缓冲参数，不是两台电脑的端到端声学延迟；网络长停顿仍会中断声音。
- .17 输入网络发送移出鼠标键盘回调，单连接顺序发送；等待时合并连续绝对鼠标移动，保留键盘、按钮和相对移动顺序。
  限制输入发送积压，网络失败按原机制重连；去掉松开鼠标按钮时固定10ms停顿和复制时强制GC。
  已确认的相同设置最多每30秒复核一次，减少重复连接；新设置仍约几秒内同步。
  音频接收认可同一已验证电脑的任一当前连接地址，避免IPv4/IPv6并存时误拒绝。
- .16 默认启用“设置同步”：任何一台修改已保存的通用设置后，已连接电脑自动交换设置。
  无固定主控；离线改动重连后比较版本，同时修改按统一版本规则选定一份，不能合并同时修改的不同字段。
  同步剪贴板、文件传输、电脑排列、跨屏选项，以及音频端口、低延迟和成对收发关系。
  本机发送对应对面接收；保留各自声卡设备和音量。首次虚拟声卡安装、默认设备和播放位置仍需本机一键配置。
  已打开的设置窗口也会刷新；音频页如有未保存修改，会提示而不覆盖输入。
  设置 → 设置同步可暂停、排除音频，或“以本机设置立即同步”主动发布当前配置。
  两台都需 .16 或更新；旧版继续正常鼠标/音频连接，但不支持设置同步。
  版本状态保存在本机 sync.json；不同步登录密码、配对码、开机启动或更新路径。
  使用现有已验证的配对连接及加密通道，不依赖 SMB 登录。配对变化后拒绝旧的同步请求。
- .16 剪贴板改为短延迟合并、Windows序号检测和读忙重试，不再丢弃一秒内的后续复制。
  助手与主程序间增加确认和断线重连，连续发送按顺序处理，文本按实际解压长度还原。
  诊断记录包含序号、类型、字节数和交付状态，不记录文本内容；最终跨机粘贴仍需两台实测。
- .15 默认开启“低延迟”：系统采集缓冲请求100→20ms，耳机播放缓冲请求100→20ms。
  音频以10ms小帧发送，发送队列最多4帧，过期音频丢弃；接收积压超过60ms时追到最新20ms。
  这些是软件缓冲参数，不是端到端实际延迟测量；声卡、虚拟设备、无线耳机和网络仍会影响听感。
  两台都更新可同时缩短采集与播放；保留旧配对、设备选择与主副角色，无需重新一键配置。
  若声音断续，可在声音与麦克风设置取消“低延迟”，保存并应用，使用原接收缓冲上限。
- .14 优化启动及断线重连：优先尝试上次通过配对验证的地址，后台继续解析新地址。
  每约2秒检查缺失连接，单次TCP连接最多等待3秒；不再等待接收端反向DNS查询。
  自动清理重复/失败尝试，音频会更快跟随鼠标连接恢复。完整配对验证与加密保持不变。
  两台都升级效果更完整；不代表提高宽带、文件传输速率或保证固定秒数内连通。
  地址提示保存在本机配置目录 connection-cache.json，绑定当前配对码且30天失效；
  地址仅用于寻找电脑，不是连接票据。更换配对码后不会继续使用旧地址记录。
- .13 新增播放位置：副电脑 → 一键配置 → 选择“仅主电脑播放”或“两边同时播放”。
  仅主电脑模式按需从官网获取 Hi-Fi Cable；首次需要联网、完成官方 Install 窗口，可能重启。
  系统声音和远端麦克风分开；切回两边播放、还原或停止共享时恢复原播放设备。
  已固定使用扬声器的应用需要改为“系统默认”并重新打开。升级不会自动改变旧模式。
- .12 音频连接修复：处理鼠标双栈连接中的 IPv4 映射地址，修复错误10049
  “在其上下文中，该请求的地址无效”。两台都应升级，保留原有主/副电脑配置，无需重配。
- 开机自动启动：设置 → 软件更新 →“登录 Windows 后自动启动（管理员权限）”。
  仅在当前 Windows 用户登录约 5 秒后启动，不需要保存密码；未登录时不会运行。

连不上时
- 确认没有同时运行 PowerToys 版本或旧独立版，且两台都使用本包。

- 核对计算机名和配对码。DNS 名称无法解析时，可在设置页的 IP 映射选项中指定名称与 IP。
- 使用重新连接快捷键；仍失败时查看 Logs 中的连接错误。

- 至少 16 个非空白字符，区分大小写。可以使用容易输入的字母、数字或短语。
- 空格、制表符和换行会自动去除；其他电脑需要输入相同内容。
- 已完成配对后，也可在设置的“电脑排列”页编辑配对码，再点击“应用”。
- 升级不会自动修改你已有的配对码。更换配对码后，需要更新其他电脑的配对码。
